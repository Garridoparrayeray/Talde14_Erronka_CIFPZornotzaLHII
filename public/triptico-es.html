Solapa · Inside flap · 01

En marcha con un solo comando.

Abre Docker, clona el repositorio y ejecuta. En cinco minutos, back-office JavaFX y portal web público, ambos sobre la misma base de datos.

QUICKSTART · TERMINAL
# 1. Clonar y entrar
$ git clone <repo> erronka-bermeo
$ cd erronka-bermeo
# 2. Todos los contenedores en marcha (db · java · web · adminer)
$ docker compose up -d
1

JavaFX desde el navegador

localhost:6080/vnc.html — sin VcXsrv ni X server, vía noVNC. Funciona igual en Linux y Windows.

2

Portal web público

localhost:8000 — catálogo responsive para ciudadanos, XML+XSLT+XPath.

3

Base de datos con Adminer

localhost:8081 — todas las tablas, triggers y procedimientos almacenados visibles.

Zero-Backend: Generador XML
Al enviar una reclamación, JavaScript captura los datos y genera un XML dinámico en memoria. Ese reclamacion.xml está listo para que los empleados lo importen en la aplicación Java y actualicen el estado del objeto.
